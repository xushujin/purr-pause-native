# 目标系统验收

本表用于补充自动测试覆盖不到的真实桌面行为。每项填写系统版本、CPU、显示器排列/缩放、应用版本、结果和证据路径；未执行的项目不标记为通过。自动测试证据见 [PARITY.md](PARITY.md)。

构建、打包、复制安装、依赖/TLS/视频资源、Cocoa 窗口属性、签名与公证均有自动步骤，见 [AUTOMATION.md](AUTOMATION.md)。以下清单中的这些检查可直接引用 CI 证据，不要求人工重复执行；缺少 macOS runner 或凭据也不视为“等待人工体验”。

## 测试环境

| 环境 | 必须记录 |
| --- | --- |
| Ubuntu 22.04 / 较新 Ubuntu，x86_64 / ARM64 | GNOME 版本、X11 或 Wayland、AppIndicator 状态、显示器工作区和缩放 |
| macOS 12，Intel / Apple Silicon | macOS 精确版本、原生 CPU 架构、是否安装到 Applications |
| 较新 macOS，Intel / Apple Silicon | macOS 版本、Space/全屏设置、登录项状态 |

完整旧工程 `purr-pause/` 已按本次明确批准移除。仓库仅在 `tests/reference/{behavior,lib,tools,renderer}` 保留原样的最小差分参考，供自动测试使用，不参与原生产品构建或安装包。若实机对照需要运行完整原版，应另行取得对应版本；测试原版与原生版时不要同时运行，共用同一套素材与配置。原生独立数据目录可用 `--data-dir /tmp/purr-pause-acceptance`；自启动验证应使用正式安装位置和默认数据目录。

## 安装和发布产物

- [ ] 从当前 commit 的 CI 下载对应架构 `.deb`、AppImage 或 DMG，校验 SHA256；记录 workflow URL。
- [ ] 在最低系统版本安装并启动，不依赖开发机的 Qt、FFmpeg 或 Homebrew 路径。
- [ ] AppImage 在未安装 Qt/FFmpeg 的桌面运行；无 FUSE 时 `--appimage-extract-and-run` 运行。
- [ ] macOS `file Contents/MacOS/purr-pause` 与机器架构一致；Apple Silicon 不依赖 Rosetta。
- [ ] macOS 签名版本通过 `codesign --verify --deep --strict`；公证版本通过 `xcrun stapler validate`，记录检查输出。无证书的 ad hoc 构建单独标注。
- [ ] 再次启动只有一个托盘/状态栏入口；退出后重新启动正常；卸载不会留下运行进程。

## 系统行为

- [ ] 托盘菜单所有入口可用；关闭设置窗口仍常驻；退出后覆盖窗口和消息轮询停止。
- [ ] 暂停/恢复/重置与剩余时间一致；30/60/120 分钟到期自动恢复。
- [ ] 真实鼠标/键盘活动计入活跃时间；闲置 3–10 分钟暂停累计；超过 10 分钟归零。
- [ ] 锁屏和系统休眠时不触发新休息；短时恢复保留累计，超过 10 分钟按原规则清零。
- [ ] 启用登录启动、注销/重新登录后仅出现一个实例；关闭后重登不启动；应用路径含空格仍正常。
- [ ] macOS 原版同路径登录项状态可读取/切换；较新系统的登录项授权状态与系统设置一致。

## 覆盖层与视觉

- [ ] 同分辨率/缩放录制四种猫咪出场，与原版比较位置、尺寸、透明度、按钮出现、倒计时与结束渐隐。
- [ ] 自定义横向/竖向透明 WebM 正常保持内容比例；损坏或缺失素材仍可结束休息。
- [ ] 动画未出现控制按钮前，点击穿透到下层应用；按钮完全出现后可点击延后/结束。
- [ ] 两台及以上显示器均出现覆盖层；在任意屏结束，所有屏一起关闭。
- [ ] 显示器不同 DPI、负坐标排列、外接/拔出和分辨率变化不使覆盖层丢失或卡住。
- [ ] 切换 Linux 工作区/macOS Space、全屏视频或全屏应用后，覆盖层行为与原版一致。
- [ ] 五个原生设置/列表窗口无文字截断、滚动不可达或高 DPI 控件重叠；图像差异逐项记录，不用“看起来接近”替代结论。

## 消息与授权

- [ ] 多来源首次同步静默；后续新待办只提醒一次；角标等于本地保留条数。
- [ ] 点击条目打开系统浏览器后本地移除；服务端不收到写请求。
- [ ] 火箭播放中开始休息并继续收到新消息，休息结束后合并补播；独立火箭演示不破坏业务通知。
- [ ] 关闭来源/模块停止轮询和角标；恢复后按首次基线规则处理；网络失败和恢复状态可见。
- [ ] 使用该平台机器码生成合法序列号，激活/续期/永久授权/重复拒绝符合原版；重启后授权保留。
